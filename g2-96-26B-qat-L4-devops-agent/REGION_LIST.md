# 🌍 Google Cloud Region & Quota Tracking

This file tracks the regions and zones used by the `find_quota` and `find_tpu` tools.

## Supported GPU (NVIDIA L4) Regions
- us-central1
- us-east1
- us-east4
- us-west1
- us-west4
- northamerica-northeast1
- europe-west1
- europe-west2

## Supported TPU Regions
- us-central1
- us-east1
- us-east5
- europe-west4
- asia-southeast1
